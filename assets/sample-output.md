# Reproducible command output

Generated by `bash assets/regenerate.sh`.

Every block below runs on the deterministic offline planner
(`VIBEFINDER_OFFLINE=1`), so it reproduces byte-for-byte on any machine, with or
without an API key. The only masked values are the run id and the log path.
